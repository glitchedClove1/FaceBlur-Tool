# Reproducible, pinned environment. Requires Python 3.12 (PyTorch has no
# Windows wheels for 3.14 yet, which is why this project pins to 3.12 via a
# dedicated venv rather than using the system Python).
#
# Setup (uv is recommended — it resolves the CUDA index correctly and is
# much faster than pip; a plain `pip install -r requirements.txt` also works
# once the venv is created with Python 3.12):
#   uv venv --python 3.12 .venv
#   uv pip install --python .venv -r requirements.txt
#
# torch/torchvision are built for CUDA 12.6 (cu126) wheels, resolved against
# this GPU (RTX 3050 Laptop, 4GB VRAM, driver supporting CUDA 13.3 — cu126 is
# backward compatible with it). If installing on a different machine with an
# older driver, swap the index-url below for an earlier cuXXX tag from
# https://download.pytorch.org/whl/torch/.
--extra-index-url https://download.pytorch.org/whl/cu126
